# محرر PDF

أداة عربية لتعديل ملفات PDF وتحويلها، تعمل بالكامل داخل المتصفح، والملفات لا تُرفع لأي سيرفر.

## المزايا
- **تعديل الكلام بضغطة:** اضغط على أي كلمة في الملف وعدّلها، والتغطية والخط والمقاس واللون تنضبط تلقائياً
- كتابة نص عربي وإنجليزي في أي مكان بالصفحة
- تغطية الكلام الموجود والكتابة بدله
- نقل الباركود أو الختم أو الشعار لمكان ثاني في الصفحة، مع تغطية مكانه القديم بلون الخلفية
- تظليل، توقيع بخط اليد، إدراج صور وأختام
- ترتيب الصفحات وتدويرها وحذفها وإضافة صفحات فارغة
- دمج عدة ملفات PDF وصور في ملف واحد
- حفظ صفحات محددة في ملف مستقل
- التحويل إلى وورد بنفس شكل الملف بالضبط: الخلفية والجداول والشعارات ثابتة، وكل نص في مربع قابل للتعديل بنفس الخط والحجم واللون
- التحويل إلى وورد كنص مرن (جداول وفقرات عادية)
- التحويل إلى صور PNG
- تحويل الصور إلى PDF

## التشغيل
افتح `index.html` في المتصفح (Chrome أو Edge). يحتاج اتصال إنترنت لتحميل المكتبات.

## المكتبات
- pdf.js 3.11.174
- pdf-lib 1.17.1
- JSZip 3.10.1
